Este proyecto es un sistema web de generación de presupuestos diseñado para una PyME de manufactura textil, desarrollado con Python (Streamlit) para la interfaz y Supabase (PostgreSQL) como base de datos. La arquitectura separa la lógica en dos archivos: core.py (modelos de negocio usando @dataclass, cálculos matemáticos y conexión a la BD mediante el patrón repositorio) y app.py (interfaz de usuario y manejo de estado de sesión). El dominio principal gestiona catálogos de telas (precio por kilo y rendimiento), productos base (consumo de tela y costo de confección), y un generador de presupuestos dinámico que calcula costos unitarios sumando técnicas de estampado (DTF), aplicando multiplicadores de ganancia y costos fijos. Un requerimiento crítico del sistema es el manejo de la inflación, por lo que los detalles de cada presupuesto guardan una copia estática del precio final al momento de su creación
